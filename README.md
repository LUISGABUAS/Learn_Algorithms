# Learn_Algorithms

Mi ruta de 24 semanas para aprender algoritmos y estructuras de datos resolviendo problemas de LeetCode. Voy de principiante a nivel entrevista técnica, con la meta de ser candidato fuerte para empresas grandes de tecnología.

Vengo del desarrollo frontend, así que este repo es donde fortalezco la parte de algoritmos. Cada solución incluye mi explicación, la complejidad y lo que aprendí.

Cómo trabajo
De 1 a 2 problemas al día, 5 días a la semana, y un día para repasar.
Intento resolverlo solo de 20 a 30 minutos. Si me atoro, estudio la solución y la reescribo desde cero sin mirarla.
Repaso cada problema a los 3 días y a las 2 semanas.
Anoto el patrón de cada problema (hash map, two pointers, sliding window, etc.) para reconocerlo rápido en uno nuevo.
La ruta
Fase	Semanas	Temas
1. Fundamentos de Python	1–3	Variables, listas, ciclos, condicionales, funciones y diccionarios
2. Arrays y Hash Maps	4–6	Frecuencias, hash tables, Two Pointers y Sliding Window
3. Complejidad y algoritmos clásicos	7–9	Big O, búsqueda binaria, ordenamiento y recursividad
4. Estructuras de datos	10–13	Stacks, queues, linked lists, árboles binarios y heaps
5. Grafos y búsqueda	14–17	DFS, BFS, grafos, shortest path y Dijkstra
6. Algoritmos avanzados	18–21	Greedy, backtracking, programación dinámica y tries
7. Entrevistas técnicas	22–24	Problemas combinados, optimización, explicación y simulacros
